# Bob Research

Read [`../../../.bob/commands/research.md`](../../../.bob/commands/research.md) completely and follow it together with the repository `AGENTS.md`.

Start with the generated indices and relevant wiki pages. Use external browsing only when it is available, authorized, and materially needed; verify external claims across reputable sources and distinguish them from wiki-derived claims.

Synthesize with citations. Preserve the work as an analysis page only when requested or when the documented preservation criteria apply and the user confirms preservation. When preserving, maintain links, rebuild the index, and append a substantive log entry.
